# C++: Техники за пределами прикладного минимума

Этот репозиторий содержит примеры кода к серии статей на Хабре **«C++: Техники за пределами прикладного минимума»**.

Цель серии — показать, как простые приёмы, часто применяемые в разработке библиотек (сильные типы, шаблонные обёртки, диспетчеризация по типам), могут качественно улучшить обычный прикладной код, делая его более надежным и выразительным, не усложняя при этом жизнь команде.

## 🛠 Как собрать все примеры сразу

Для сборки всех частей серии одной командой используйте CMake из корня проекта:

```bash
cmake -S . -B build
cmake --build build
```
