# C++: Техники за пределами прикладного минимума

Этот репозиторий содержит примеры кода к серии статей на Хабре **«C++: Техники за пределами прикладного минимума»**.

В прикладном коде традиционно доминирует минимализм. Это оправдано, но часто оставляет вне поля зрения элегантные решения.

В этом цикле мы разбираем продвинутые техники C++ (сильные типы, Tag Dispatching, Type Traits) и смотрим на привычные конструкции под другим углом. Цель — изучить возможности, которые позволяют сделать код выразительнее и безопаснее, а также разобрать границы их применимости. Использовать их в своем проекте или нет — решать вам.

## 🛠 Как собрать все примеры сразу

Для сборки всех частей серии одной командой используйте CMake из корня проекта:

```bash
cmake -S . -B build
cmake --build build
```
