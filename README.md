# Applied C++: Library Approach

Этот репозиторий содержит примеры кода к серии статей на Хабре **«Прикладной C++: Библиотечный подход»**.

Цель серии — показать, как инженерные практики из мира разработки библиотек могут качественно улучшить обычный прикладной код, делая его более надежным, выразительным и производительным.

## 🛠 Как собрать все примеры сразу

Для сборки всех частей серии одной командой используйте CMake из корня проекта:

```bash
cmake -S . -B build
cmake --build build
```
